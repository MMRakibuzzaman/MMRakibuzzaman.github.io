# Rakibuzzaman's Portfolio Website

This repository contains the source code for my personal portfolio website, built using modern Angular and styled with Angular Material and custom CSS variables supporting automatic light and dark themes.

## Tech Stack
*   **Frontend**: Angular, TypeScript
*   **UI Library**: Angular Material (Animations, buttons, transitions)
*   **Styling**: Custom CSS custom properties (variables) supporting `prefers-color-scheme`
*   **Hosting**: GitHub Pages
*   **CI/CD**: GitHub Actions (auto-builds and deploys on push to `main`)

## Getting Started
To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/MMRakibuzzaman/MMRakibuzzaman.github.io.git
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm start
   ```
4. Open [http://localhost:4200](http://localhost:4200) in your browser.
